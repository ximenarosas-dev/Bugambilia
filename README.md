# 🌸 Bugambilia

A personalized bouquet website designed and developed with WordPress.

## ✨ About the project

Bugambilia is a web project created for a fictional flower shop focused on personalized bouquets and a friendly, visually appealing shopping experience.

The project combines web design, visual identity and WordPress development, with a focus on responsive design and a cohesive visual style.

## 🎨 Design

The visual identity was designed specifically for the project, including:

- Logo and visual elements
- Color palette
- Typography
- Layout and page structure
- Responsive design
- Custom visual details
- Animated banner created with Canva
